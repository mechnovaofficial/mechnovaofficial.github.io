New-player eligibility: a practical workflow

  1. Use the correct account. Sign in to the game account that should receive the reward. A new device or a reinstall does not, by itself, prove that an account meets a new-player rule.
  2. Check the campaign wording. Look for terms such as newly created account, eligible account, platform-specific promotion, campaign end date or one-time use. Do not assume every “new player” code uses the same time window.
  3. Separate codes from offers. A starter pack link can open a store offer rather than a promo-code field. Check whether a price, purchase condition or extra eligibility requirement appears before continuing.
  4. Redeem one code at a time. Enter the exact spelling using the official method, then read the success or error message. Avoid repeatedly submitting a code when the game explains that the account is not eligible.
  5. Check the actual reward. Look in the in-game Inbox or inventory as instructed. Keep a note of the result and do not rely solely on an external page saying “claimed.”

Common mistakes new players make

Assuming every code works on every account

Public posts often omit campaign restrictions. An offer may target a particular cohort, platform or region. Treat “new player” as a clue to investigate, not as proof of eligibility.

Confusing a possible reward with a guaranteed reward

If a promotion opens crates or lists possible contents, distinguish those possibilities from the reward you receive automatically. Read the full in-game description before deciding whether the offer is worth pursuing.

Following an unofficial redemption link

Use the redemption option in the game or the official Plarium destination linked from publisher instructions. A legitimate code should not require your game password, one-time password, account recovery details or payment-card information on a third-party site.

Protect your account

Never share passwords or one-time codes with code sites. A third-party page cannot make an account eligible for a publisher-controlled promotion.
