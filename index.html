How to Redeem a Promo Code

Choose the steps for your device. The game's menus and promotion rules can change, so follow the current in-game instructions.
🖥️

PC & Android

Redeem from the game when the Promo Codes option is available.
  1. Open Mech Arena and sign in to the account that will receive the reward.
  2. Open your Inbox, then choose Promo Codes.
  3. Paste an eligible code and confirm it.
  4. Check the result and claim the reward from your in-game Inbox.
📱

iPhone & iPad

Some iOS redemptions continue in the official activation page.
  1. In Mech Arena, open your Inbox and tap Promo Codes.
  2. If the game opens an activation page, enter your Player ID and the code there.
  3. Confirm the redemption, return to the game and check your Inbox for the reward.
New Player codes may have a short redemption window, often the first 24 hours after account creation. Check each code’s eligibility and any campaign-specific rules. Only enter account details on an official page opened by the game; never share your password or OTP.

How MechNova Checks Promo Codes

A practical way to read code status, eligibility and reward claims without confusing reports with guaranteed results.

Promo-code information can become outdated quickly. A code appearing in a video, community post or old screenshot is a reason to investigate, not proof that it will redeem on every account today. MechNova separates the code listing from the final result determined by the game publisher.

  1. Look for the closest primary source. Check the in-game News/offer screen and official Mech Arena or Plarium announcements when available. Community discussions may help locate a code but can omit restrictions.
  2. Check who can use it. Read account-age, returning-player, platform, region, expiry and one-time-use conditions. Do not assume codes share the same rules.
  3. Identify the offer type. A redeemable code, a store pack, an event milestone and a random crate opening are different. Verify the exact item or amount promised by the campaign.
  4. Confirm the outcome safely. Use the official redemption route and read the in-game message. Check the Inbox or inventory as instructed; never provide a password or one-time code to a third-party code service.

How to interpret a status note

Label or evidenceWhat it tells youWhat it does not prove
ListedThe code has been recorded in a MechNova category.That it is currently redeemable for every account.
Source reportedA source or announcement mentions the code or reward.That the source's conditions apply to your account today.
Submitted successfullyA redemption attempt returned a success message.That another player or platform will receive the same result.
Expired / not workingThe listed campaign may have ended, or an attempt failed under the recorded conditions.That every code with the same name has the same status for all accounts.

When a source is unavailable or a reward cannot be independently verified, the responsible choice is to label the uncertainty rather than invent a result. For the detailed publishing approach, read the Editorial Policy. To report a broken link or status correction, use Contact MechNova.

⌕Where can I find new codes?+

There is no fixed release schedule. Codes may come with updates, events or official campaigns. Check MechNova’s current code list and read each code’s eligibility and status.

!Why isn't my code working?+

It may have expired, be for another account type, already be redeemed, or have a cooldown. Copy it exactly and check the code’s notes. The game’s message is the final guide.

🎁Where are my rewards?+

Make sure the game accepted the code, then open your in-game Inbox and claim the reward message. If it still does not arrive, contact official in-game support. Never share your password or OTP.

◷Can I redeem multiple codes?+

Different eligible codes may be redeemed over time, but cooldowns or account limits can apply—sometimes around 24 hours. New Player codes are often limited to eligible new accounts. Follow the message shown in-game.

↻How often are new codes released?+

There is no guaranteed schedule. Watch for official updates, seasonal events and creator campaigns, and check the current list before redeeming because codes can expire.
