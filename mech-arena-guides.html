How to use these guides

Start from your actual question. If you need a code, open the code list. If you already have a code but it fails, go to the redemption walkthrough. If a video promises a mech, use the reward guide to establish whether that item is supplied by a code, a store offer, an event milestone or a random crate.

Check information in context. Time-sensitive codes and offers can expire, while mech balance and weapon behaviour can change. Read the review date, original source and account conditions where provided. When a guide cannot independently confirm an item or outcome, it should say so rather than present an assumption as a fact.

Use the in-game result as the final check. An external code list can help you discover an offer, but the game determines whether an account qualifies and whether the reward was delivered. Never share passwords, one-time codes or recovery information with a third-party code service.

How MechNova handles corrections

We aim to separate publisher-confirmed information from dated listings and community reports, and to distinguish redeem codes from packs and event rewards. If you spot an outdated label, broken link or unclear explanation, send the exact page URL, code or offer name, and the non-sensitive error text through the Contact page. Do not include private account details.
